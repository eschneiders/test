Make changes visible to visitors

Your edits are saved in this browser so you can preview instantly. To show them to visitors on every device, publish: copy the data below into js/data.js (or download it) and re-upload your site. Why?

This is a static site with no server, so there's no shared database. That keeps it free and fast to host — the trade-off is that publishing changes means updating the site's files. Ask your developer to wire up a backend if you'd like edits to go live automatically.
