      Make changes visible to visitors

      Your edits are saved in this browser so you can preview instantly. To show them to visitors on every device, publish: copy or download the data below and send it to your developer (or paste it back here) to update the live site. Why?

      This is a static site with no server, so there's no shared database — which keeps it free and fast to host. The trade-off is that publishing changes means updating the site's files. A small backend can make edits go live automatically; ask your developer if you'd like that.
